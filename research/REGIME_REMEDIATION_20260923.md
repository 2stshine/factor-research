# 레짐·교훈 개선 실행 기록

사용자 요청: 입력 진단/최신성 → 미검토 교훈 → 큰 4분류 → 한국 생산·물가 방향 → 매매 시점 연결 순서로 개선.

기존 팩터·연구 결과·OOS·승격 기준은 바꾸지 않는다. 과거 교훈은 공개된 보관 증거만 해석하고,
자료 없는 원인을 만들지 않는다. PIT_ASSUMED 정책은 유지한다. 실제 주문이나 신규 팩터 평가는 없다.

| 단계 | 상태 | 산출물 / 완료 조건 |
|---|---|---|
| 1. 입력 진단·최신성 | 구현 완료 | 공통 가격/선언 입력/통제 입력 역할 분리; 과거 커버리지와 최신 완료월 판독 상태 분리 |
| 2. 미검토 175건 교훈 | 저장 완료 | 개별 증거 해석 + 독립 비평 완료; 공개 교훈 177건 검토 완료, 미검토 0건 |
| 3. 큰 4분류 중심 해석 | 구현·공개 배포 완료 | 4분류 기본, 16분류 보조; 미관측·표본 부족·구간 수 의미 표시 |
| 4. 한국 생산·물가 방향 | 생성·독립 검토·등록 완료 | 6개월 as-of snapshot 규칙; 새 campaign부터 동결, 기존 campaign 불변 |
| 5. 매매 시점 연결 | 계약·날짜 정합성 검증 완료 | 실제 종목 체결·비용·수익성은 미검증이며 주문하지 않음 |

## 1. 최신성

`scripts.regime_snapshot`은 `configured_and_usable`이 과거 이력 보유를 의미함을 명시하고,
`freshness`, `current_ready_contexts`, `all_current_states_ready`, `stale_context_ids`를 별도로 기록한다.
원본 부족을 채우거나 기존 상태/승격 gate를 변경하지 않는다.

- 최종 실행: `python -m scripts.regime_snapshot --registry research/regime_sources.json --as-of 2026-09-23 --output output/regime_inputs/remediation-20260923-final`
- 새 방향 입력 포함 39축 중 과거 사용 가능 39축, 마지막 완료월 2026-08 판독 가능 38축.
- 로컬 KOSPI 원본 마지막 partition: 2026-07-16. 기존 동결 시장 완전월은 2026-06.
- 2026-08 최신 판독에는 이 시장 입력을 사용할 수 없으며 UNKNOWN/STALE로 표시한다.
- 테스트: `test_regime_freshness.py`, `test_assumed_regime_integration.py` 27개 통과.

새 `raw-input-profile-v2`는 adj_close/adv20 등 공통 시장 컬럼을 진단한다. 실제 사용 추적과
혼동하지 않게 역할·단위 미확인·누락 컬럼을 표시한다. 기존 연구 packet은 변경하지 않는다.
가격 진단 focused 테스트 76개 및 관련 교훈/레짐 회귀 99개가 각각 통과했다(중복 합산하지 않음).
독립 최신성 검토에서 승인 scope 전 워밍업 자료를 무자료로 표시하던 사례를 발견해 수정하고 회귀 테스트를 추가했다.

## 2. 교훈 정리 절차

공개 허용된 보관 packet 175개를 각 연구별로 읽고 가설·저장 계산식·전체 검사·집계를
대조해 초안을 작성했다. 서로 다른 작성자와 비평자가 대조하며, 수정 요청은 문장과
판정만 고치고 새 hash에 대해 다시 비평한다. 팩터 계산식·연구 결과·gate는 바꾸지 않는다.
175개 모두 과거 상세 진단 여덟 구역이 미수집이므로 원인·국면 차이를 새로 입증하지 않는다.
교훈 검토 완료는 신규 실험이나 독립 실증 재현을 뜻하지 않는다.

`scripts.lesson_review_batch`는 공개 상태·packet hash·현재 근거·서로 다른 역할·현재 초안에
결합된 ACCEPT를 재검사한 뒤 단일 writer로 저장한다. 원본 변화 및 미완료 journal은 차단한다.
이 도구는 경제적 해석이나 ACCEPT를 자동 생성하지 않는다.

2026-09-23에 175건을 실제 저장했다. 전체 원장 203건 중 공개 허용 177건은 모두 검토 완료이며,
비공개 PENDING 26건은 그대로다. 기존 검토 2건과 비공개 26건의 내용 hash, 원본 연구 파일
fingerprint가 저장 전후 일치함을 확인했다. 이후 registry에 새 파생 입력만 별도로 등록했다.
저장 receipt는 `research/memory/lesson_review_batches/2a11221337b6b8386a5f18dd27b5eb327a77e9ad1d78aad3563c42b83a9728ff.json`이다.
검토본은 content-addressed `research/memory/lesson_reviews/`에 보존하고 KNOWLEDGE를 갱신했다.
별도 역할의 최종 무결성 점검에서도 175건의 원장·보관본·근거·비평 결합 검증을 통과했다.
원본 1,066파일의 저장된 stat fingerprint 대비 추가/삭제는 없으며 registry 한 파일만
승인된 파생 입력 추가로 변경됐다. 봉인 파일의 내용을 새로 읽어 hash 검증했다는 뜻은 아니다.
독립 비평 중 비율 설명의 분자·분모 혼동, 실제 측정하지 않은 경제 경로 단정 등을 수정했다.
과거 미수집 가격 진단이나 국면별 성과를 새로 만들어 넣지는 않았다.

## 3. 큰 네 국면

대시보드 기본 비교는 장기 추세 × 장기 변동성의 UP_LOW / UP_HIGH / DOWN_LOW / DOWN_HIGH다.
장·단기 네 축은 보조 설명, 세부 열여섯 조합은 탐색용으로 남긴다. 빈 상태와 UNKNOWN도 보존한다.
가장 성과가 좋은 상태를 선택한 것이 아니며 기존 분류 공식과 연구 수치를 변경하지 않았다.
관측이 연속된 구간 수와 다른 상태를 사이에 둔 발생 수를 구분하고 어느 쪽도 독립 재현으로 부르지 않는다.

## 4. 한국 생산·물가의 방향

- 새 버전: `kr-production-inflation-direction-v1`.
- 입력: 승인된 가정 경로의 한국 산업생산 YoY와 CPI YoY, 각 월말 당시 선택된 값.
- 고정 규칙: 최근 세 판단월 값의 평균에서 이전 세 판단월 평균을 차감한다.
- 여섯 연속 판단월, 당시 가용, 최대 경과 육십 일 조건을 요구한다. 미래값·빈 월을 채우지 않는다.
- 두 차이의 부호로 네 상태를 나누며 정확히 영인 축은 NEUTRAL, 조건 미충족은 UNKNOWN이다.
- 2015-01~2026-08의 140개월 중 134개월 분류, 최초 2015-07. 최신은 생산 방향 상승·물가 방향 상승이다.
- 상태 수: 생산상승·물가하락 22, 동반상승 47, 생산하락·물가상승 24, 동반하락 37, 중립 4, 미확인 6.
- 79개 판단창에 같은 발표 관측 재사용이 있어 lineage에 표시했다. 새 발표 여러 개로 세지 않는다.
- 제공자 event date는 통계 기준월이 아니다. 부모 데이터에 없는 기준월은 추정해 채우지 않는다.
- `PIT_ASSUMED`를 유지한다. GDP 성장률·공식 경기침체·물가수준 하락·최초 발표본 인증이 아니다.

원본은 `output/regime_inputs/kr-production-inflation-20260923-v1/`에 별도 생성했다.
기존 연구에 새 국면별 성과를 소급 붙이지 않는다. `research/regime_sources.json`에 등록해
새 캠페인부터 기본 동결되는 진단 입력이다. 현재 총 39축은 검증 입력 1축과 가정 입력 38축이며,
새 방향은 기존 두 시계열에서 파생한 분류이지 새 원본 매크로 데이터가 아니다.
일별 RV63 분류는 이번에 구현하지 않았다. 기존 월별 변동성 공식을 몰래 바꾸지 않는다.

## 5. 판단 시각과 거래 가능 시점

`month-end-next-session-timing-v1`은 한국시간 달력 월말 종료 판단 후, 공급된 달력의
다음 거래일 시가를 요구한다. 같은 월말 종가 체결이나 임의의 평일·오전 아홉 시를 추정하지 않는다.
입력 가용시각 ≤ 판단시각 < 실행시각, 다음 거래일 일치, 양의 유한 가격 등을 검사하며
실제 거래가능 종목 가격·검증된 달력·보유/비용 계약이 없으면 실행 인증을 하지 않는다.

보관 KOSPI 입력의 2015-01~2026-06 신호월 138개에 대해 다음 관측 거래일과 해당 KRX 원본의
KOSPI 시가지수 138개를 해시·행 정체성까지 연결했다. 결과는
`output/regime_inputs/execution-alignment-20260923-v1/alignment.json`에 있다.
이는 **138개 날짜·지수 참조 정합성**이지 체결 검증이 아니다. 실제 개장 시각, 매매 가능한 종목의
체결가격, 보유내역과 비용을 갖춘 모의집행은 남아 있다. 기존 연구 수익 label은 수정하지 않았다.
