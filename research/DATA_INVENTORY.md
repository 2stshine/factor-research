**현재 활성: 108개·27,754,980행·66개 불변 dataset.** 공매도 2개를 v2로 교체했으며 나머지 106개와 구버전 Gold는 보존했다.

`reference_sources/new_information/krx-short-eligibility/`에 SHA256 검증 후 보관했다.
일반 금지일·개별 제한일은 제외하고, 허용일 원천 결측은 0으로 대체하지 않는다.
최소 15개 허용·가용 거래일 및 전일 관측을 요구한다. `PIT_ASSUMED`이고 대차·주문별 체결 가능성의 증명은 아니다.
[결과·정의·실행 증거](../docs/reference-short-eligibility-20261004.md), [활성 program](phenomena/program.json).

**교체 전 기록: 108개·27,734,862행·66개 불변 dataset.** 아래 100개를 보존하고

## 기존 원천 인벤토리 확인 범위

확인 기준: 기존 KRX/DART/한투/FMP 일일 항목은 2026-09-18,
추가 FMP Bronze 세 묶음은 **2026-09-20 S3 적재·재조회 검증 증빙** 기준이다.
이번 갱신은 FMP 추가 보유분 반영이며 기존 항목 전체를 재조회한 것은 아니다.
아래는 운영 증거와 현재 연구 입력 목록에서 확인한 범위다.
전체 DB의 실시간 카탈로그는 아니며, 목록에 없다는 이유만으로 미보유라고 판단하지 않는다.
최신 적재일은 실행마다 달라진다. 표의 날짜는 마지막 확인값이며 실시간 보장을 뜻하지 않는다.

**2026-10-02 재무 입력 후속 감사:** 인증 재무 원장 2,275,046행·3,076자산을 실제 추출하고
수정된 TTM 계산으로 별도 로컬 패널을 재생했다. 2015년 원문 공시 9건과 매출 staging
36값셀도 로컬 확보했으나 PIT 미승인·Silver/Gold 미게시·공식 입력 미연결이다.
매출 성장가속도 입력 coverage는 수정 후 56.3223%, 월별 하위 십분위 0%로 FAIL이다.
운영 가격 generation이 2026-10-01까지 갱신되어 원래 가격 부모 패널과도 불일치하므로
이번 새 패널은 감사용·미활성이다. 아래 과거 연결 표를 현재 실행 승인으로 읽지 않는다.
상세와 구분된 증거는 [재무 입력 복구 기록](../docs/research-v2-fundamental-repair-20261002.md) 참조.

2026-10-01 연구 v2 연결 감사에서는 **2026-09-22 Silver 확장 검증 문서**도 대조했다.
FMP 전체 재무·회사 관측과 DART 구조 이벤트·원계정 매핑의 추가 보유 증거가 있다.
아래 기존 적재 이력과 문서 끝의 후속 연결 감사를 함께 읽는다. 이번에는 DB를 재조회하지 않았고,
보유 증거를 현재 연구 패널 연결·회사별 역사 커버리지 인증으로 바꾸지 않았다.

후속 PIT 상태: 한국 기준금리의 공식 결정 대조 **월말 진단 입력 1개(2015-01~2026-08)**를 승인하고
새 캠페인 기본 입력에 등록했다. 로컬 Silver 정제본이며, Bronze 37계열 전체 승인이나 RDS 적재는 아니다.
상세 근거는 문서 끝의 한국 정책금리 정제 승인 항목을 참조한다.
2026-09-21 후속 검증에서는 나머지 36계열 47,378행을 검사하고 COT 전수 수치 대조,

위 10월 1일 항목은 당시 연결 상태의 기록으로 보존한다. 다음은 이후 도입한 **운영 코드와
증거 전달 계약**의 갱신이다. 새 Bronze/Silver 적재량, 전 기간 coverage, 최초 발표 빈티지
재인증을 뜻하지 않는다. [일반 연구 운영 안내](../docs/research-v2-production.md)가 이후 실행
상태의 기준이며, [여섯 정의 파일럿 완료 기록](../docs/research-v2-completion-20261002.md)과 구분한다.

| 항목 | 보유·원천 상태 | 새 운영 경로의 연결 | 여전히 구분할 한계 |
|---|---|---|---|
| 기존 Silver 주식·재무 입력 | 기존 인증 패널과 계정 allowlist 유지 | 본 Discovery가 계산한 패널·신호를 그대로 진단에 전달하고, 가설별 분모·결측·가용시점·필요 이력을 계약에 기록 | 입력 존재와 후보별 계산 가능성은 다름. 후보 입력 검사 통과는 수익성·경제 가설 검증이 아님 |
| KOSPI·KOSDAQ 일간 지수 | 기존 로컬 원본과 사용자 PIT 가정 정책 | 새 campaign에서 일간 위험 기반 분류를 동결하고 두 시장을 각각 진단. 범위 밖·워밍업은 UNKNOWN | 새 원본 적재나 전체 달력·최초 빈티지 인증이 아님. 기존 campaign과 완료 파일럿을 소급 재분류하지 않음 |
| FMP·한국 매크로 보조축 | 기존 검증/가정 registry와 원본 계보 유지 | 후보가 결과 전에 정한 최대 두 축과 대비 상태만 진단에 연결. 조합 전수탐색 없음 | 연결 가능한 축이 모든 기간에 가용하다는 뜻은 아님. PIT_ASSUMED를 VERIFIED로 변경하지 않음 |
| 가설별 경제적 결과 | 해당 Discovery에 연결된 인증 Silver 재무 계정 범위 | 사전등록한 계정의 이후 수준/변화와 양의 분모·공시 가용시점·관측 성숙 조건을 확인. 모든 가설에 ROA를 자동 대입하지 않음 | 자료가 연결되지 않으면 NOT_CONNECTED. 미래 사업연도 실적·현금흐름·기대 대비 surprise 전부를 측정한다는 뜻이 아님 |
| 가설별 재무 통제·과거 업종 | 시장·규모·유동성 통제는 기존 입력 사용. 당시 업종은 별도 원천 계약 필요 | 사전등록 재무 비율 통제는 인증 필드·가용시점을 요구. 업종은 역사적 가용일·검증 근거 hash가 있는 경우에만 연결 | 현재 FMP 프로필을 과거 업종으로 소급하지 않음. 업종 미연결과 조직 전체 데이터 부재를 구분 |

| 검토된 교훈과 다음 연구 맥락 | 기존 활성 정성 기억과 원래 범위·근거 보존 | 정확한 새 범위의 절차적 전이 제안·독립 비평 ACCEPT·검색 및 사용/배제 영수증을 후보 등록에 결합 | 연구자가 지금 배운 교훈을 과거 신호일에 알았다고 소급하지 않음. 전이 승인도 새 범위에서 경제적 효과가 재현됐다는 의미가 아님 |

**이 갱신 시점의 실제 진행:** 신규 후보의 입력 검사와 독립 검토를 거친 기억 전이·사용 기록까지
진행했다. 최초 운영 캠페인 `v2-production-20261002-cost-intensity`는 수익률 평가 전에 운영
감사 경로를 보완하기 위해 결과 없이 `CLOSED_ABORTED`로 보존했고, 같은 후보의 새 캠페인은
별도 동결 대상으로 남겼다. 이 문서에 신규 수익률·OOS·승인·Gold 적재·새 교훈 완료를 기록하지 않는다.

원본 보유 → 연구 패널 연결 → 후보별 입력 검사 → 실제 진단 → 독립 교훈 검토의 상태를 각각
남긴다. `NOT_CONNECTED`, `NOT_COMPUTED`, `INSUFFICIENT_SUPPORT`를 가설 반증이나 완료로
바꾸지 않으며, 데이터 확보 요청도 실제 수집·적재·사용 승인과 구분한다.

**같은 날 후속 실행 결과:** 수정 버전 `v2-production-20261002-cost-intensity-v2`도 동결하고
독립 검토된 절차적 기억의 실제 검색·사용을 완료했다. 그러나 Gold 신호 상관 사전검사 FAIL로
후보 등록 전 `CLOSED_ABORTED / OOS NOT_USED`가 되었다. 기존 CLI의 실패 상세 미보존 때문에
상관 초과와 비교 월 부족 중 어느 조건인지는 확인하지 못했다. 입력 coverage 91.97% PASS와
구분한다. 신규 수익률 평가·운영 진단 세션·실증 교훈·OOS·Gold는 모두 0건이며, 코드 도입 및
기존 파일럿 검증을 이 신규 연구의 전 과정 완료로 세지 않는다. 상세는 위 일반 운영 안내 참조.
