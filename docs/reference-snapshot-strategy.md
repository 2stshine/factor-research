2026-10-16 사용자 요청: 앞으로 전략 탐색은 현재 보유한 스냅샷으로 실행한다.
업데이트가 밀렸거나 최신 DB 계약이 BUILDING이어도 이 경로는 갱신이나 로그인을 요구하지 않는다.
새 Gold 적재·입고 승인·월초 TR 정식 평가의 검증 규칙은 변경하지 않는다.

## 바로 실행

저장소 루트에서:

```bash
# 전체 보유 이력: 기본 2017-01~2026-08 신호, 결과는 2026-09까지
.venv/bin/python -m scripts.run_reference_snapshot run \
  --output output/phenomena/my-snapshot-run

# 동일한 월별 학습을 최대 4개 프로세스로 병렬 실행 (모형/기간은 동일)
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
  .venv/bin/python -m scripts.run_reference_snapshot run --workers 4 \
  --output output/phenomena/my-parallel-snapshot-run

# 짧은 실제 입력 확인
.venv/bin/python -m scripts.run_reference_snapshot run \
  --first-month 2026-07 --last-month 2026-08 \
  --output output/phenomena/my-snapshot-smoke
```

같은 명령·출력 폴더로 재실행하면 월별 체크포인트를 재사용한다. 설정·코드·입력 해시가
다르면 기존 결과를 덮어쓰지 않고 새 출력 폴더를 요구한다. 전체 이력의 모델 학습 시간은
별도로 소요되지만 데이터 갱신·네트워크·AWS·DB 인증은 수행하지 않는다.

`research/phenomena/snapshot-strategy-defaults.json`이 기본 파일과 스냅샷 해시를 고정한다.
원천 캐시가 나중에 갱신되거나 활성 program이 바뀌어도 이 실험은 동결된 버전을 계속 쓴다.
원천 캐시를 다시 읽는 준비 작업은 최초 한 번만 필요하며 이미 완료했다.

```bash

# 다른 스냅샷은 명시해서 사용; 기본 포인터는 자동 변경하지 않음
.venv/bin/python -m scripts.run_reference_snapshot run --snapshot <새 경로> --output <새 결과 경로>
```

## 실험의 정확한 의미

| 항목 | 오프라인 탐색 | 기존 정식 실행 비교 |
| --- | --- | --- |
| 데이터 | 고정 로컬 파일 | Gold live 연결과 실행 입력 검증 |
| 수익률 | 인접 월말 수정가격의 가격수익 | 다음 첫 거래 시가→다음 리밸런싱 시가 TR |
| 배당 포함 | 입증하지 않음, TR로 표시하지 않음 | 입력 계약으로 확인 |
| 체결 | 월말 정보·같은 월말 가격을 짝지은 탐색 근사 | 월말 판단 후 다음 월초 시가 모형 |
| 비용 | 보유 비중 변동 후 모형상 매수·매도 금액 × 각 25bp | 실제 교체 비중·연도별 세금·비용 모형 |
| 시장 비교 | 시장 TR 미확보는 null | 시장 TR + 유니버스 동일가중 |
| 승인 | 탐색 결과만, 자동 승인 없음 | 별도 검토 필요 |

기본 비용은 매수·매도 각각 25bp를 **거래한 금액에만** 적용한다. 전월 보유 종목의
가격 변동을 반영한 평가액과 이번 목표 보유액의 차이를 거래한다. 최초 진입은 매수만,
마지막 강제 청산은 제외한다. 비용 차감 후 자산 안에서 투자액을 풀어 현금 부족을 방지한다.
단가는 실제 수수료·연도별 세금·시장충격을 입증한 값이 아닌 비교용 가정이다.
`--buy-bps`, `--sell-bps`로 각각 사전 지정한다. `--round-trip-bps`만 지정하면 절반씩 적용한다.
구 버전의 매월 50bp 일괄 차감은 비교용으로만 보존한다. 기존 월별 체크포인트의
`net_return_cost_scenario`와 `result.json/summary`는 이 **레거시 비교치**다.
현재 비용 성과는 `result.json/primary_result`가 가리키는 `turnover-result.json`을 사용한다.
월말 종가 이후 공시까지 사용할 수 있는 결정시각이므로 같은 종가 매수는 실제 체결 불가능할 수 있다.
이 제한은 데이터가 낡았다는 문제와 별개이며 결과에 계속 표시한다.

세 모델(전체/선택/선택+PCA) × 네 바스켓(20%/10% × 동일/√시총)을 동일한 입력으로 계산한다.
학습은 최대 60개월·최소 24개월/1,000행이며, 학습 label은 그 월말까지 종료·가용한 것만 쓴다.
전처리·IC 선택·상관 제거·PCA·릿지는 학습 자료 안에서만 적합한다. 기존 30개 선택·10성분·alpha 10을 유지한다.
PCA 차원이 부족하면 해당 모델-월은 미실행으로 남기며, 몰래 차원을 바꾸지 않는다.
과거 결과 재사용은 새 독립 OOS가 아니다. PIT_ASSUMED도 최초 발표값 검증으로 바뀌지 않는다.

## 결측과 결과 파일

- 보유 이후 가격이 없는 종목을 미리 유니버스에서 제외하지 않는다.
- 인접 달이 없으면 더 먼 달 가격으로 수익률을 만들지 않는다.
- 선택 종목 중 결과가 하나라도 없으면 해당 포트폴리오-월은 `UNRESOLVED_MISSING_OUTCOMES`다.
- 불완전한 월을 빼고 누적/연율 성과를 이어 붙이지 않는다. 전체 구간 CAGR·낙폭은 null로 남긴다.
- 실행과 가정 비교는 계속한다. 별도 `missing_outcome_sensitivity`에는 미확인 종목의 수익을
  0%(가격 유지) 또는 -100%(전액 손실)로 가정한 두 경로를 함께 남긴다. 둘 다 관측 성과가 아니며,
  신뢰구간이나 가능한 수익률의 상·하한도 아니다. 종목 선택·비중은 두 가정에서 동일하다.
  결측 종목 목록과 비중도 기록하므로 어떤 가정에 의존하는지 확인할 수 있다.
- 관측 가격행 유니버스에 없는 상장폐지 종목 등을 완전 복원했다는 뜻은 아니다.

`plan.json`: 기간·모형·비용·입력/코드 해시를 결과 계산 전에 고정.
`months/YYYY-MM.json`: 학습기간, 선택 입력, 모델 계수, 바스켓 종목/비중, 결측과 월별 수익.
`result.json`: 12개 비교 요약과 미완료 월 수, 한계, 미승인 상태.
`turnover-result.json`: 현재 기본 거래금액 비용의 월별 매수·매도·NAV·비용·회전율,
두 결측 가정별 성과와 전체 동일가중 기준선. 가정 경로를 확정 관측 CAGR로 읽지 않는다.

완료된 실행은 다음 명령으로 읽기 쉬운 로컬 HTML 보고서를 만들 수 있다.
모든 월의 체크포인트 해시와 요약을 다시 대조하고, 같은 비용/결측 가정의 전체 동일가중
기준선·연도별 수익·선택 빈도를 `analysis.json`에 함께 저장한다. 새로운 모델을 학습하거나
결과로 설정을 바꾸지 않는다.

```bash

  --run output/phenomena/my-parallel-snapshot-run \
```

  사용자 실제 계좌·과거 전 기간의 수수료를 검증했다는 뜻은 아니다. 추가 유관기관 비용을
  이중 가산하지 않는다. 세금·수수료·슬리피지 원장을 별도로 남긴다.
- 거래세: 매도만 부과하며 KOSPI 농특세 포함/KOSDAQ 합계 30→25→23→20→18→15→20bp.
  달력 연도가 아니라 공지의 **매도 체결일 경계**로 적용한다. 2025-12-29부터 20bp 등
  연말 선적용을 반영한다. 자료 확인일 이후 세율을 임의 연장하지 않는다.
- 슬리피지: 한쪽당 0/5/10/25bp를 모두 보고하며 결과로 단가를 선택하지 않는다.
  실제 호가·주문금액·체결로 추정한 시장충격은 아니다.
- 실제 세율 적용일은 저장된 KRX 마지막 거래일을 이용한다. 월말 가격 근사라는 실행
  한계는 그대로이며 다음 월초 실제 체결로 이름을 바꾸지 않는다.
- 12개 조합 × 두 결측 가정 × 네 슬리피지 시나리오. 최초 매수만/강제 마지막 청산 제외.
- KOSPI/KOSDAQ 공식 가격지수는 같은 시작·종료일로 비교하며 비용 없는 지수다.

진단은 시장 → 시장 내 규모 → 같은 시장·규모 안 종목 구성 순서의 기술적 회계 분해다.
규모는 당시 시총 1조원 이상, 3천억원~1조원, 3천억원 미만의 자체 구분이다.
각 셀의 비교수익은 보유 패널의 당시 시총가중으로 계산하고, 이 패널과 공식 시장지수의
차이를 별도 잔차로 둔다. 독립적인 인과 효과나 공식 KOSPI 구성종목의 완전 복제가 아니다.

매월 분해 합계는 전략 순수익률-KOSPI 수익률과 일치해야 한다. 누적 분해는
`전월 전략 NAV × 해당 월 효과 × 이후 KOSPI 수익 배수`로 연결해 최종 자산 차이와
정확히 일치시키며 연복리 수익률 차이로 오표시하지 않는다. 결측 두 가정은 비교 셀에도
동일하게 적용하고 누락 비중을 기록한다.

**업종 귀속은 미완료**다. 로컬 가격 패널에는 당시 종목별 업종/효력일이 없고 회사 프로필은
과거 효력을 보장하지 않는다. KRX 업종지수의 2025/2026 수익률은 환경 설명으로 제공하되,
현재 업종을 과거로 소급하거나 이를 전략의 업종 기여도로 주장하지 않는다. 필요한
종목별 과거 분류 및 벤치마크 업종 비중은 `result.json/data_requirements`에 남긴다.

출력: `plan.json`, `benchmarks.json`, `slippage-{0,5,10,25}.json`,
`attribution.json`, 요약 `result.json`, 한국어 `report.html`.
기존 Gold·DB·스냅샷·전략 종목·모형은 변경하지 않는다.

실행 확인: 비용 4개 × 결측 가정 2개 × 전략 12개 × 116개월, 총 11,136개
포트폴리오-시나리오-월을 재계산했다. 독립적으로 직전 보유 평가액·목표액 차이의
매수/매도·세금·슬리피지·말기 NAV를 재구성했고 저장 NAV 오차는 0이었다.
시장/규모 분해 2,784개 월별 항등식 및 누적 연결 합계도 통과했다. 관련 테스트 129개 통과.
`execution-audit.json`에 검증 범위를 기록했다.

대표 PCA·20% 동일가중의 연율은 결측 0% 가정에서 슬리피지 0/5/10/25bp별
8.34%/7.76%/7.18%/5.47%, 결측 -100% 가정에서 4.95%/4.39%/3.84%/2.18%다.
동일 기간 KOSPI 가격지수는 연 13.17%다. 전체 기간 평균 보유 비중은 KOSDAQ 70.43%,
시총 3천억원 미만 90.12%였다. 이 노출과 최근 대형주/전기전자 상승은 분리해 해석하며,
당시 종목별 업종 배분의 기여도는 아직 자료 부족으로 식별하지 못했다.
