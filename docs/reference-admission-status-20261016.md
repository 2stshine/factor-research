## 사용자 요청으로 후속 진행 보류

**총수익 파이프라인 복구와 실제 전략 수익률 평가는 이번 작업에서 진행하지 않는다.**

1. 현재 DB의 KRX `total_return_close` 계약은 `BUILDING`이다. 인증 해제 사유는
   `DART_BRONZE_ACTION_CHANGE_OBSERVED_BEFORE_PUBLICATION:2026-10-09`다.
   이는 배당 포함 수익률 라벨의 상태이며 이번 동결 Gold 측정값 입고 판정과 별개다.
2. 실제 월초 시가 체결 입력 묶음은 로컬 검사에서 확인되지 않았다.
   발견된 `input_bundle.json`들은 소프트웨어 테스트용 합성 자료다.
3. 공식 첫 거래 세션, 거래 가능 시가, 배당·기업행위가 조정된 시가→시가 총수익률,
   같은 구간의 시장 총수익률, 당시 유니버스·시총·가용시각의 연결을 확인해야 한다.
   최신 DB 메타데이터 감사에서도 시가 총수익 계약과 별도 세션 테이블은 확인되지 않았다.
   외부 파일까지 포함해 자료가 전혀 없다고 단정한 것은 아니다.
4. 실제 관측 비교의 비용 후 성과, 108개별 수익률 기반 기여도, 최종 전략 취사선택 판정은
   산출하지 않았다. 입고 확정과 전략 승격을 혼동하지 않는다.
