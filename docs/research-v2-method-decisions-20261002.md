# 연구 v2 실제 진단 파일럿의 방법 결정

2026-10-02 · 기존 결과를 고치지 않는 새 프로토콜 · 문헌과 코드 검토에 따른 운영 결정

## 1. 여섯 정의를 다시 측정하는 이유

이번 파일럿의 대상은 **새 알파 발굴이 아니라 같은 팩터에 대해 교훈 진단을 수행하는 절차**다.
기존 정의 색인에서 성과를 보지 않고 세 경제적 계열의 단일 팩터 두 개씩을 정하고,
정의 파일 SHA·계산식·방향·룩백·데이터 버전·허용 기간을 결과 전에 동결한다.
기존 승인 여부나 높은 IC를 선택 이유로 쓰지 않는다. 이름만 바꿔 새 후보로 등록하지 않는다.

Chen–Zimmermann은 기존 수식·방향·표본·포트폴리오 구성을 기록하고 원 연구 재현과
재분석을 구분한다. 따라서 입력이나 진단 프로토콜을 변경하는 우리 실행은 엄밀히
동일 결과 재현이 아니라 **프로토콜 재분석(PROTOCOL_REANALYSIS)**이다.
원 연구의 통계적 결과 재현과 실제 거래 이익도 별개의 질문이다.
[연준 원문 §2.2–2.3 및 서론](https://www.federalreserve.gov/econres/feds/files/2021-037pap.pdf).

JKP의 표준화된 구성과 팩터군별 비교는 정의를 고정한 비교의 참고가 된다. 해외시장 재현
결과를 한국시장 효과나 현재 진단 엔진의 우월성으로 옮기지 않는다.
[Jensen–Kelly–Pedersen, 2023](https://onlinelibrary.wiley.com/doi/full/10.1111/jofi.13249).

6개월·12개월 모멘텀처럼 같은 계열의 두 정의를 미리 지정하는 것은 **민감도·절차 비교용**으로
허용할 수 있다. 좋은 쪽을 골라 새 발견이라고 발표하지 않으며, 두 정의를 두 독립 경제적
발견으로 세지 않는다. 결과는 정의별로 모두 보존하고 계열 중복을 표시한다. 입력이 부족하면
그대로 자료 부족을 보고한다. 성과를 본 뒤 대체 후보를 채우지 않는다.

## 2. 판정과 설명의 종료 조건을 분리한다

정해진 검사를 모두 자유 선택으로 바꾸는 것도, 모든 가설에 모든 자료를 강제하는 것도 피한다.
**무엇을 주장할 것인가**에 따라 필수 증거를 정하고, 검사 순서와 추가 진단은 선택하게 한다.

| 주장/작업 | 반드시 확인하거나 부재를 명시할 증거 | 허용되는 결론 |
| --- | --- | --- |
| 입력 적합성 | 시점·단위·계정·결측·양의 분모·원계산 재현 | 측정 가능 / 부족 / 구현 문제 |
| 예측 관계 | 동결 신호와 다음 달 수익의 월별 관계·표본·불확실성 | 관측 연관성, 인과 아님 |
| 경쟁 설명 구분 | 사전 지정 규모·거래활동 등 대안의 동일 표본 비교 | 특정 설명과 부합 / 구분 불가 |
| 경제적 메커니즘 | 신호→경제적 결과 및 경제적 결과→가격 관계, 성숙한 outcome | 경로와 부합할 수 있음, 인과 확인 아님 |
| 국면별 교훈 | 사전 지정 국면별 월수·발생 구간·효과·결측 | 제한된 조건부 관측 / 표본 부족 |
| 실행 가능성 | 실제 가용시각·체결가격·보유규칙·비용·같은 창의 기준수익 | 전략 성과 / 미검증 |

- 빠른 판정 목적은 해당 판정에 필요한 증거가 있으면 종료할 수 있다.
- 깊은 설명 목적은 등록한 경쟁 설명 각각을 검사 결과·표본 부족·미보유 자료로 처리해야 한다.
  한 원인을 찾았다는 이유로 다른 필수 설명을 조용히 생략하지 않는다.
- 필수 자료가 없으면 `UNTESTED`와 자료 요청을 남긴다. 이는 가설이 거짓이라는 뜻도,
  설명을 충분히 검증했다는 뜻도 아니다. 확보 불가능한 자료 때문에 무한히 기다리지 않는다.
- 예산 소진은 `BUDGET_EXHAUSTED_INCOMPLETE`이지 교훈 검증 완료가 아니다.
- 음성대조는 주장 경로의 영향이 없고 교란을 공유한다는 이유가 있을 때만 사용한다.
  단순 셔플은 계산 오류 검사에는 유용하지만 자동으로 유효한 경제적 음성대조가 되지는 않는다.

POPPER에서 차용하는 것은 측정 가능한 함의·경쟁 설명을 구분할 다음 실험을 선택하는
구조다. 논문의 순차 오류 통제는 이전 정보에 조건부로 유효한 각 검정과 논리적 함의 등의
가정을 요구한다. 같은 금융 패널에서 결과를 보고 통제·국면을 고르는 현재 진단은 그 조건을
입증하지 않았다. 그러므로 p값을 e값으로 바꿔 곱하거나 "POPPER 수준의 오류 통제"를
주장하지 않는다. 진단은 탐색적이고 기존 승인 gate는 별도로 유지한다.
[POPPER ICML 원문 §2.3–3](https://cs.stanford.edu/~jure/pubs/auto-hypothesis-validation-icml25.pdf).

금융의 반복 시행과 선택은 원장에 남긴다. 사전등록·기억 초기화·새 이름은 과거 노출을
없애지 않는다. 이번 재분석은 새 독립 OOS 확인으로 표시하지 않는다.
[Harvey–Liu–Zhu, 2016](https://people.duke.edu/~charvey/Research/Published_Papers/P118_and_the_cross.PDF).

## 3. 실제 고정/선택형 진단 비교에서 측정할 것

동일 정의·자료·질문·진단 도구·예산과 필수 증거를 두 방식에 제공한다. 고정 경로는
사전 순서를, 선택형은 앞선 허용 관측을 보고 다음 검사를 선택한다. 한 경로의 최종 답이나
다른 경로만 본 결과를 상대에게 넘기지 않는다. 공통 입력 계산은 재사용할 수 있지만
사용한 증거·실행 요청·총 계산·모델 비용을 구분해 기록한다.

주요 지표는 근거 없는 주장, 필수 설명 누락, 미검증의 정직한 표시, 추가 자료 요청의
구체성, 판단 근거 추적성, 전체 시간·비용이다. 절약한 진단 단위를 실제 원화 비용 절감으로
바꾸어 표현하지 않는다. 큐레이터와 별도 비평 비용도 포함한다.

실제 금융 자료에서는 원인을 아는 정답지가 없다. 따라서 독립 비평은 증거의 실재·인용·범위와
미수집 설명을 평가할 수 있으나 **경제적 원인 정답률**을 측정한 것이 아니다. 합성 오류 주입
사례의 정답률, 실제 연구의 근거 충실도, 앞으로의 성과 검증을 각각 분리한다. 여섯 정의의
결과는 통합 흐름 확인이며 일반적 우월성이나 통계적 비열등성 증명이 아니다.

Praxist의 결과를 근거·성숙도·운영 역할이 있는 finding으로 바꾸는 방식은 채택하되,
최고 점수의 반복 탐색이나 메커니즘 조합을 단일 팩터 승인 규칙에 도입하지 않는다.
[Praxist §2.3–2.5](https://arxiv.org/html/2608.25955v1).

## 4. B0/B1/B2 기억 평가의 범위

| 구성 | 달라지는 것 | 달라지면 안 되는 것 |
| --- | --- | --- |
| B0 | 활성 경험 기억 없음 | 공통 정책·문헌·정의/시도 색인·도구 |
| B1 | 출처와 범위가 있는 교훈의 저장·검색 | 데이터·질문·정답 접근·평가 기준 |
| B2 | 별도 큐레이터의 확인·정정·은퇴 | 미래 과제나 숨겨진 정답 접근 |

ReasoningBank는 성공·실패 경험을 재사용 가능한 교훈으로 축약한다. 그러나 자기평가로
작성한 기억이 반드시 참인 것은 아니다. 우리 활성 교훈에는 근거 ID·적용 범위·미확인을
남기고, 경험이 없으면 검색 0건을 허용한다.
[ReasoningBank §3.2](https://arxiv.org/html/2509.25140v2).

Grounding Agent Memory처럼 작업 세션과 이후 큐레이터를 분리한다. B2의 probe는
허용된 스키마·계정·계산 재현 등 읽기 전용 확인에 한정한다. 성공한 과제의 모든 중간
가정을 참으로 승격하지 않는다. 원자료나 숨겨진 성과를 더 읽어 새 경제적 검정을 하는
행위는 probe가 아니라 새 실험이다.
[Grounding §3.2–3.3 및 Appendix D](https://arxiv.org/html/2609.11060v1).

평가는 오류 원인/fixture 계열을 개발·평가 사이에 나눠 과제 문구만 바꾼 누출을 피한다.
동일 모델과 세션 격리, 구성별 저장소, 동일 과제 순서를 사용한다. 동결 기억의 새 과제 평가와
순서대로 학습하는 online 평가는 다르다. 후자는 `답 제출→채점 봉인→허용 피드백→기억 갱신`
순서다. 정답을 제공하는 실험과 운영 가능한 피드백만 제공하는 실험도 구분한다.
규칙 기반 모의 planner나 단위 테스트의 성공을 실제 LLM 기억 비교 성공으로 보고하지 않는다.

MemRL식 효용은 알파·승인 수가 아니라 연구 수행의 근거 충실도·오류 방지에 연결한다.
우선 순위를 바꾸지 않는 관측 모드로 기록한다. 여러 기억에 공동 보상을 주면 어느 기억의
인과적 기여인지 알 수 없으며, 같은 과제 반복의 개선과 새로운 과제 전이를 구분한다.
[MemRL §4.2–5.2](https://arxiv.org/html/2601.03192v2).

## 5. 새 레짐의 제한적 채택

기존 shadow의 사전 고정 수치는 그대로 유지한다: **10개월 이동평균 거리,
일별 로그수익 63개 위험, 21/63 위험 비율, 직전 연속 12월 RV63 중앙값과 상대 위치**.
KOSPI와 KOSDAQ은 따로 계산한다. 연율화 252와 표본 표준편차를 사용하며 현재 월을
상대 위험 기준에 넣지 않는다. 월말 t의 지표를 t+1 결과와 연결한다.

Moreira–Muir는 과거 일별 관측에서 위험을 측정해 다음 월에 적용한다. 이는 일별 위험 측정의
참고이며 우리 63/21/12 창의 최적성이나 한국 적용 성과를 증명하지 않는다.
[저자 원문 §I.B](https://amoreira2.github.io/alan-moreira.github.io/VolPortfolios_published.pdf).
10개월 추세는 Faber의 월말 규칙을 참고한다. 역시 유일한 최적 룩백이라는 뜻은 아니다.
[Faber 원문](https://mebfaber.com/wp-content/uploads/2016/05/SSRN-id962461.pdf).

LOW/HIGH 개수를 절반씩 맞추는 것이 목표가 아니다. 분포가 이동하면 rolling 기준의 LOW도
절대적으로 위험할 수 있으므로 **절대 RV63·추세 거리·위험 변화·백분위**를 함께 유지한다.
라벨은 설명용 요약이며 시장 예측 정답이나 매매 신호로 승인하지 않는다. 국면·거시 축의
모든 조합을 자동 탐색하지 않고 가설별 소수 축을 사전에 고정한다. 표본 부족은 UNKNOWN 또는
INSUFFICIENT_SUPPORT로 남기고 최상의 국면만 고르지 않는다.

새 `engine/research_regime_adoption.py`는 기존 shadow를 수정하지 않고 원본/공식/달력/정책
hash와 허용 신호월을 묶는 **새 PIT_ASSUMED 진단 계약**만 만든다. 원본의 PIT_UNKNOWN,
NOT_APPROVED는 그대로 보존하며 계약 채택 시각과 가정한 역사적 가용 시각을 분리한다.
기존 캠페인·생산 registry·팩터 입력·승격 gate·Gold는 변경하지 않는다. 정책은 사용자가
수용한 기존 가정을 사용하며 최초 발표값 전수검증을 다시 실행의 전제조건으로 만들지 않는다.

`exchange_calendars` 4.13.2 XKRX와의 차이는 라이브러리에만 있는 2026-06-03·2026-07-17
