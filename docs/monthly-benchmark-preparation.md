# 월초 벤치마크 입력 — 조건부 산술 및 원천 검사 v1

현재 실제 성과는 **0/196**이다. 이 도구는 공식 자료가 도착했을 때 자료의 정의와 시각을
대사하기 위한 로컬 초안이다. 자료를 수집하거나 계정을 만들지 않고, 월초 비교 실행기·동결
계획·봉인 기간·DB를 바꾸지 않는다. 출력은 기존 실행기가 받는 입력 스키마가 아니다.

## 정확한 요청 범위

기존 동결 계획은 신호월 2018-03–2026-05의 99개월이다. 다음 달 첫 세션에 진입하고 그다음
달 첫 세션에 청산하므로, 필요한 개장값은 **2018-04–2026-07의 100개**다. 마지막 청산을
6월로 줄이면 원래 계획과 다른 실험이 된다. 달이나 결측 종목을 빼서 공통기간을 맞추지 않는다.

`python -m scripts.check_monthly_benchmark --plan <동결 plan.json> --output <새 초안.json>`은
자료가 없어도 필요한 100개 개장월과 미충족 99개 구간을 정확히 남긴다. `--sources`를 주면
원천 파일 해시와 동결 allowed-data 경계를 먼저 확인한다. 원천을 읽기 전에 기존 `load_plan`의
구현·계획 해시, 봉인/shadow 기간 검사를 거친다. 출력은 불변이며 종료 코드는 항상 2다.

## 종가 비율로 시가 TR을 만들지 않는 이유

[KRX 총수익지수 방법론, 발행사 제공 사본 1–2쪽](https://download.kiwoom.com/web/KiwoomEtnRuleBook7.pdf)은
가격지수 수익과 배당 지수포인트를 더해 총수익을 산출한다. 같은 기준시점의 공식 구성요소가
있다면 조건부 산술은 다음과 같다.

```
TR(open) = TR(previous close) × [PR(open) + DI(as-of open)] / PR(previous close)
```

`TR(close) / PR(close) × PR(open)`은 배당 지수포인트를 단순 비례시켜 배당일에 다른 값을 낸다.
개별 주식의 사후 정정 종가 TR도 이 지수 구성요소의 대체물이 아니다. DI는 확정·취소 정정으로
음수일 수도 있으므로 값이 없음을 0으로 채우지 않는다. 중간 날짜의 배당과 공식 보정이 이미
반영된 전일 TR 종가 자체가 필요하다.

이는 원천 조건에 따른 산술일 뿐이다. 공급자 반올림·정밀도·공식 계산값의 수치 대사는
미완료로 남기며 `execution_certified=false`, `actual_fill_verified=false`를 유지한다.

## 공급자에게 필요한 자료와 증거

| 구분 | 필요한 것 | 현재 충족되지 않은 조건 |
| --- | --- | --- |
| 지수 식별 | 정확한 KRX300 gross TR, 원화, 대응 가격지수 및 공식 식별자 | 이름이나 OHLC 필드만으로 TR을 인증하지 못함 |
| 개장값 | 공식 총수익 개장값 또는 위 식의 공식 구성요소 | scheduled open / 주식 첫 체결 / 지수 첫 발표를 구분해야 함 |
| 시간·세션 | 100개 첫 세션과 전 세션, 예외 개장시각, 지수 관측시각 | 일반 09:00을 전 기간에 가정하지 않음 |
| 배당 지수포인트 | 해당 개장시점의 예정·확정·취소 버전, 출처와 가용 시각 | 최신 정정값의 소급 사용과 구분 필요 |
| 초기 구간 | 2018-12-24 발표 시작 전의 공식 백캐스트 자료와 버전 | 실제 당시 공표·실거래 자료로 표시하지 않음 |
| 권리 | 기존 계정의 조회/분석 허가 및 재배포 범위 | 무료 조회가 원자료 공개 허가라는 뜻이 아님 |
| 원문 보존 | 공급자 파일 바이트 hash, 방법론·검토 참조, 버전 경계 | 숫자 복사나 검증 플래그만으로 인증되지 않음 |

첫 세션의 지수 관측시각이 계획한 개장시각과 다르면 현재 조건부 도구는 거부한다. 일별 시가만
있어서 실제 시각을 모르는 경우도 통과하지 않는다. 실제 체결·유동성·슬리피지는 별도 문제다.
발표 시작 전 자료는 공식 백캐스트로만 받을 수 있고, 그 나중 발표 버전을 명시하며 동결된
자료 허용시각 이내인지 검사한다. 과거 당시에 알려져 있던 관측으로 표시하지 않는다.

`official-index-components-source-v1` manifest는 `contract`, `points[]`, `source_files[]`를 받는다.
모든 개장점은 contract의 같은 `series_revision_id`에 결합해야 한다. 백캐스트의 발표 버전은
`backcast_series_release_at`으로 고정하여 서로 다른 정정본을 섞지 않는다.
정확한 최소 필드와 실패 예시는 `tests/test_monthly_benchmark_preparation.py`의 합성 fixture에 있다.
합성 자료의 `data_kind=SYNTHETIC_TEST`는 결과에도 보존한다. 이 fixture를 역사 시장 자료로
이름만 바꾸어 사용해서는 안 된다. 실제 원천의 진실성은 별도 검토가 필요하다.

## 확인한 확보 경로와 결정이 필요한 부분

- 기존 로컬 Bronze의 요청기간 6,102파일에서 명시적 TR/NTR 이름은 확인되지 않았다.
  이는 해당 경로·지수명 조사 결과이며 모든 보유 자료에 없다는 단정은 아니다.
- KRX Marketplace의 해당 시계열 조회는 로그인이 필요하다. 이미 보유한 계정/파일로 정확한
  시가·TR 범위를 확인하는 경로가 남아 있다. 새 가입·권한 확장은 실행하지 않았다.
- [KRX OPEN API 안내](https://openapi.krx.co.kr/contents/OPP/COMM/notice/OPPCOMM001_S2.cmd?bbsSeq=5)에
  따라 허용된 API/화면 경로만 사용한다. 누락 범위를 비공식 수집이나 로그인 우회로 채우지 않는다.
- [금융위원회 지수시세정보](https://www.data.go.kr/data/15094807/openapi.do)는 2020년 이후 제공·키가
  필요한 경로여서 현재 2018–19 범위를 그대로 충족하지 못한다. 새 키를 만들지 않았다.

현재 계획을 유지하려면 기존 보유 파일/권한으로 위 조건을 충족하는 공식 자료를 확보해야 한다.
만약 불가능하면 **새로 사전등록할 별도 비교**에서 종가→종가, 가격지수, 더 짧은 기간 중 하나를
선택할 수는 있다. 각각 체결 시점·배당 포함 여부·관측기간이 달라지므로 지금의 196개 성과로
대신 표시하지 않는다. 어느 대안도 자동으로 채택하지 않았다.

이 자료 외에도 개별 주식 시가 총수익, 정정 기업행사·상폐 정산, Gold 점수의 원천 가용시각과
역사적 universe/cap 연결, 최종 입력 번들 인증이 남아 있다. 외부 지수 파일만 확보되면 즉시
196개 결과가 완성되는 상태는 아니다. `docs/monthly-input-preparation.md`의 경계를 함께 읽는다.


### 최종 시점 용어

동결 계획의 마지막 신호 2026-05는 2026-06 첫 개장에 진입해 2026-07 첫 개장에 평가한다.
`last_exit_liquidation=false`이므로 마지막 평가에서 강제 청산 매도·청산 비용은 넣지 않는다.
본문의 exit/청산 경계는 수익 구간의 끝이며 실제 매도가 실행됐다는 뜻이 아니다.
