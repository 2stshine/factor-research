# 연구 판단 에이전트 비교와 현재 연구 구조

2026년 10월 1일. 이 보고서는 새 연구 구조의 판단 능력을 합성 사례에서 비교하고,
현재 구현 범위와 실제 팩터 연구에 남은 연결 작업을 구분한다. 한국 주식의 수익률을
비교한 보고서가 아니며, 새 팩터 승인이나 과거 연구의 재평가도 아니다.

## 이번 비교의 결론

실제 LLM 24건과 고정 체크리스트 24건을 모두 완료했다. 주 질문의 정답과 인용 근거
일치는 두 방식 모두 24건 중 24건이다. LLM은 진단 비용 단위를 168에서 138로
17.9% 줄였지만, 복합 원인 사례 두 건에서 국면 차이를 추가로 확인하지 않았다.
따라서 **간단한 판정은 정상 작동하지만 더 깊은 교훈을 얻는 데 우월하다고 볼 수 없다.**

| 지표 | 간결한 고정 검사 | 실제 LLM 선택 |
|---|---:|---:|
| 완료 | 24/24 | 24/24 |
| 주 질문 정답과 실제 인용 근거 일치 | 24/24 | 24/24 |
| 근거 없는 구조화 결론 또는 발견 코드 | 0 | 0 |
| 필요한 자료를 올바르게 요청 | 2/2 | 2/2 |
| 불필요하거나 잘못된 자료 요청 | 0 | 0 |
| 행동 거절 또는 실행 실패 | 0 | 0 |
| 진단 비용 단위 | 168 | 138 |
| 검사와 종료를 포함한 행동 수 | 96 | 86 |
| 복합 사례의 추가 국면 차이 발견 | 2/2 | 0/2 |

두 방식은 24개 사례와 12개 계열 모두 주 결론 정확도에서 동률이다.
수익 질문 16건은 각각 16/16이며 비용 단위는 142 대 112다. 경제 질문 8건은
각각 8/8, 비용 단위도 각각 26으로 같다. 경제 진단은 각 방식에서 6번 실행됐고,
나머지 두 경제 사례는 입력이 잘못됐음을 먼저 확인해 종료했다.

절감된 30단위는 정확히 **국면 검사 10번을 생략한 결과**다. 각 검사의 비용은 3이다.
주 질문에 답하는 데 충분하다고 멈춘 점은 효율적이지만, 생략한 검사 중 두 번에는
추가 설명이 있었다. 두 복합 사례에서 업종·규모 노출과 비용 소멸을 확인한 뒤
멈췄으므로 주 결론 MIXED는 타당해도 국면 차이에 관한 교훈은 얻지 못했다.
검사하지 않은 국면을 안정적이라고 주장한 것은 아니다.

이것이 이번 시험에서 얻은 핵심 설계 교훈이다. **판정 목적과 설명 목적의 종료 기준을
구분해야 한다.** 예측 관계가 비용을 견디는지만 묻는 작업은 일찍 멈출 수 있지만,
국면을 포함해 효과가 달라지는 이유를 연구하는 작업에는 미확인 설명을 남겨야 한다.
다음 실제 연구에서는 질문별 필수 증거를 먼저 정하고, 추가 진단 순서와 자료 요청을
에이전트에게 맡기는 방식을 비교할 예정이다. 이번 결과에 맞춰 현재 실행을 다시
돌리거나 점수·원래 판정 기준을 고치지는 않았다.

사전 규칙의 자동 결과는 제한된 적응형 후속 비교 후보 조건을 충족한다.
이는 운영 기본값 변경 명령이 아니다. 깊은 설명을 목적으로 하는 연구의 기본 검사를
당장 적응형으로 대체하지 않으며, 실제 데이터 연결 후 별도로 비교한다.
좋은 성적은 강한 신호와 분명한 오류를 포함한 합성 사례에서 나온 것이다.
현실적인 작은 효과·누락·수정 이력·새 문제 계열에서 같은 성적을 보장하지 않는다.

별도 검토자가 LLM 종료 설명 24건과 인용 수치를 확인하고 양쪽 세션 48개의 계약·해시를
대조했다. 인과 증명이나 실제 시장 성과로 과장한 서술은 찾지 못했다.
다만 간단한 조건부 중단 규칙도 비슷한 절감을 얻을 가능성은 남는다. 그 비교기는
이번에 동결·실행하지 않았으므로 LLM만의 추가 가치를 분리해 입증하지 못했다.

### 부가 채점 항목의 표현 한계

원래 결과의 `missed_findings_vs_generator`에는 두 방식 모두 자료 부족 코드가
두 건 누락됐다고 표시된다. REQUEST_DATA 행동에는 STOP의 findings 배열이 없기 때문이다.
실제로는 모두 해당 누락 보고서를 읽고 정확한 필드를 요청했다. 주 결론·자료 요청 지표에는
정상 반영됐으므로 이를 자료 부족을 놓친 실패로 해석하지 않는다.
원래 결과 파일은 보존하며, 이 부가 목록의 한계를 검토 기록에 따로 남긴다.

## 비교 대상과 사전 조건

고정 체크리스트와 실제 LLM이 동일한 사례를 각각 풀도록 했다. 12개 생성 계열마다
새로운 seed 두 개를 사용해 방식별 24건이다. 코드·계획·사례·기준을 실행 전에
동결하고 모든 사례가 끝나기 전에는 부분 점수를 공개하지 않는다.

| 질문 | 사례 수 | 고정 체크리스트 | 확인하는 것 |
|---|---:|---|---|
| 수익 관계 | 16 | 입력 검사 → 업종·규모·유동성 통제 → 비용 → 국면 차이 | 미래정보 혼입, 노출 설명, 비용 소멸, 국면 차이, 약한 관계 |
| 경제적 설명 | 8 | 입력 검사 → 경제적 결과 연결 | 예상한 두 연관성이 있는지, 자료가 부족하면 무엇을 요청하는지 |

고정 방식에서도 입력이 잘못됐으면 바로 멈추며 필수 자료의 누락이 확인되면 자료를
요청한다. 원래 상관관계를 이미 포함하는 통제 검사 앞에 중복 상관 검사를 넣지 않는다.
경제적 질문에는 불필요한 거래비용 검사를 강제하지 않는다. 각 방식의 상한은 사례당
10 진단 비용 단위와 10 행동이며, 조기 종료해도 남은 예산을 억지로 쓰지 않는다.

LLM은 사례마다 별도 컨텍스트에서 자기 공개 packet만 보고 진단을 선택한다.
정답·생성 코드·다른 사례·실제 시장 데이터는 연구자에게 전달하지 않는다.
파일시스템 권한을 분리한 것은 아니므로 접근 격리는 논리적 절차다.
정확한 공개 prompt와 선택·거절·결과는 사례별 해시 연결 원장으로 남긴다.

## 무엇을 좋은 결과로 판단하나

정답을 맞히는 것과 근거 있는 결론은 따로 채점한다. 예를 들어 미래정보 혼입을
우연히 맞혔어도 입력 검사를 하지 않았다면 확인한 발견으로 인정하지 않는다.
경제적 연관성이 불확실하면 그 경로가 입증되지 않았다고 적되, 원인이 없다고 확정하지 않는다.

자료 요청도 단순히 많이 하는 것이 좋은 결과는 아니다. 실제 누락 보고서를 인용하고
정확한 필요한 필드를 요청했는지 본다. 검사하지 않은 경제적 원인을 자료 부족으로
바꾸지 않으며, 인과관계는 모든 경우 미확인이다.

동률이면 단순한 고정 체크리스트를 기본으로 남긴다. 적응형의 판단이 나쁘지 않고
검사 수를 줄이거나 추가 정답을 얻었다면 제한된 실데이터 후속 비교의 후보가 된다.
LLM 토큰·금전 비용은 측정되지 않았으므로 진단 비용 감소를 전체 운영비 절감이라고
표현하지 않는다. 24건은 알려진 합성 계열의 반복이지 새로운 시장에서의 독립 검증이 아니다.

## 연구 구조가 돌아가는 방식

1. 가설과 변경하면 안 되는 조건을 먼저 고정한다. 신호 수식, 대상 종목, 기간, 룩백,
   비용을 결과에 맞게 바꾸는 권한은 에이전트에게 주지 않는다.
2. 에이전트가 가능한 설명을 비교하고 다음 검사를 선택한다. 업종 때문인지,
   규모 때문인지, 비용 때문인지 등을 구분할 관측을 예상한다.
3. 등록된 실행기가 수치를 계산한다. 입력 범위와 예산을 검사하고 원장에 기록한다.
   LLM이 직접 수치를 지어내거나 임의 SQL을 실행하는 구조가 아니다.
4. 결과를 본 에이전트가 다음 검사, 자료 요청, 판단 유보, 종료 중 하나를 선택한다.
   새 검사 제안은 자동 실행하지 않고 미실행 검토 대상으로 남긴다.
5. 종료하면 사실, 가능한 설명, 미확인 사항을 나누어 검토한다. 검토된 실제 연구의
   교훈만 다음 연구에 쓸 수 있으며 합성 정답을 한국 시장의 경험적 교훈으로 넣지 않는다.

현재 1~4는 합성 데이터에서 연결되어 실행된다. 실제 팩터의 전체 흐름과 검토된 기억
활성화까지 끝났다는 뜻은 아니다. 기존 팩터 승격·최종 검증·Gold 게시 계약은 별도로 유지한다.
진단의 CONDITIONAL은 국면별 관계 차이를 뜻하며 팩터의 조건부 승인 등급이 아니다.
통제 후 IC와 원신호 포트폴리오의 비용 후 수익도 별도 검사다. 이를 업종·규모를
중립화한 실제 매매 포트폴리오가 비용 후에도 수익을 냈다는 뜻으로 합쳐 설명하면 안 된다.

## 실제 데이터와 레짐 준비 상태

가격·재무 입력은 별도 캐시로 갱신했고 2026년 9월 30일 기준 RDS 자산 identity와
일치한다. 자산·월 736,679행, 재무 스냅샷 94,282개이며 최신 유니버스는 2,493종목이다.
기본 운영 캐시는 바꾸지 않았다. DART 현금흐름과 자산의 지정 3기업 연결도 성공했지만,
모든 가설·전체 기간의 경제적 결과 커버리지가 확인된 것은 아니다.

레짐 원본은 9월 말까지 갱신했고 새 보조 판독은 시장별 141개월 중 126개월이
판독 가능하다. 일별 변동성과 연속 값을 보존하며 기존 운영 레짐은 교체하지 않았다.
판독 가능 개월 수는 분류가 미래 수익을 잘 설명한다는 정확도가 아니다.

입력 룩백은 가설에 필요한 이력과 경제적 결과의 관측 기간을 구분하는 계획기를
추가했다. 모든 팩터에 3년 입력을 강제하지 않도록 새 계약에서 실제 필요 기간을
결합해야 한다. 최종 검증용 OOS 36개월을 줄인 것은 아니다.

## 다음 실제 연구에 필요한 것

가장 가까운 다음 작업은 그래프 기억을 더 복잡하게 만드는 것이 아니라,
갱신된 실제 패널에서 허용 기간·컬럼·출력 범위만 내보내는 진단 연결이다.
그 위에 사전등록한 소수 가설의 입력과 경제적 결과 커버리지를 확인하고,
같은 예산의 고정 검사와 적응형 검사를 비교한다.

경제 자료가 없다고 별도의 수익 예측 연구까지 실패로 처리하지 않는다.
다만 실제 근거 없이 경제적 원인을 확인했다고 기록하지 않는다. 기존 노출 기록을
보존하므로 이미 본 과거 OOS를 새 미노출 구간으로 다시 이름 붙이지 않는다.
