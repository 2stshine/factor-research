# 현상 중심 연구 프레임워크 구현·검증 보고서

작업 시작 2026-10-02, 최종 확인 2026-10-03(KST). 이번 범위는 새 연구 실행 틀과
검증 가능한 레퍼런스 측정 라이브러리다. 실제 시장 가설의 확인이나 수익성 승인이 아니다.

## 새 연구의 흐름

```text
현상 질문 → 경쟁 설명 → 관측 가능한 예측·전제가 명시된 논증
                         ↓
             필요한 자료가 있는가?
             ├─ 있음 → 원천·시점·범위 검토 → 고정 입력
             └─ 없음 → 내부 목록 / 공급자 / 실제 웹 검색
                         → 허용된 원본 확보·검증 또는 NO_EVIDENCE
                         ↓
      호스트 연구자가 다음 검사와 이유 선택 → 제한된 실행기
                         ↓
     관측값 + 반대 근거 + 한계 → 별도 검토자 → 범위가 있는 주장
                         ↓
           검색 가능한 지식 그래프의 고정 스냅샷
                         ↓
         별도 전략 명세 → 월초 체결·비용·벤치마크 비교
                  └─ 학습 내 선택 / PCA / 릿지
```

새 정보는 과거 주장을 재검토 대상으로 만들며, 원천이 무효화되면 관련 주장과 전략의
현재 사용을 차단한다. 과거 실행 기록은 지우지 않는다. 논증 간선은 시장의 인과관계 인증이 아니다.

데모의 합성 교훈은 이 그래프에 이관하지 않았다.

## 실제 레퍼런스 입력·계산

16개 문헌 정의 중 현재 검증된 가격 입력으로 계산 가능한 7개를 연결했다.
인증 가격 입력은 **2015-01~2026-09, 역사적 종목 3,160개, 종목-월 320,056행**이다.
이는 현재 상장기업 전수 커버리지 통계가 아니며, 기업 단위가 아니라 역사적 종목 단위다.

| 레퍼런스 | 계산된 값 수 | 최초 월 | 최신 월 |
|---|---:|---|---|
| 종목 시가총액 로그 | 320,056 | 2015-01 | 2026-09 |
| 12–2 가격 모멘텀 | 282,871 | 2016-01 | 2026-09 |
| 1개월 가격 반전 | 316,894 | 2015-02 | 2026-09 |
| 일간 저변동성 | 291,010 | 2015-10 | 2026-09 |
| Amihud 비유동성 | 307,900 | 2015-01 | 2026-09 |
| 252관측일 고점 근접도 | 282,465 | 2016-01 | 2026-09 |
| 월간 최대 일수익 MAX | 318,685 | 2015-01 | 2026-09 |
| 합계 | **2,119,881** | | |

계산 값은 raw 측정치이며 방향은 catalog에 별도 저장한다. SMB/Mom/BAB 같은 원 논문의
롱숏 포트폴리오 수익을 그대로 복제했다는 뜻이 아니다.

다음 9개는 정의와 필요한 자료를 기록했지만 적재 대상에서 제외했다:
장부가/시가, 이익수익률, 매출총이익/자산, 영업 수익성, 자산 성장, 발생액,
저베타/BAB, QMJ, 시장 TR−원화 무위험 수익. 계정·결산기·기업 대응·PIT 또는 시장/RF 계약과
계산 adapter가 더 필요하다. 임의 대체 계정으로 채우지 않았다.

원천에서 보통주로 분류됐으나 종류주 표시와 충돌한 `00104K`와 `37550L`은
2종목·140종목-월을 격리했다. `0037T0` 같은 신규 영숫자 코드는 문자열로 보존했다.

## Gold 발행과 전수 대사

**실제 DB commit 완료: 2026-10-03 00:12:03 KST.**
7개 정의·2,119,881개 값을 새 Gold에 발행했고, 모든 행을 212개 binary 청크로 대사했다.
기존 Gold metadata 동일성을 확인한 뒤 commit했으며 기존 값 수정은 0건이다.
활성 `research/phenomena/program.json`이 다음 정확한 dataset을 지정한다:
`7f26985eab9cb2a7bf59aac109b142139072a5a8d0cd4fd8ea6e59dbcbe9859a`.

영수증:
`output/phenomena/reference-build-20261002-v4/publish-receipt-7f26985eab9cb2a7bf59aac109b142139072a5a8d0cd4fd8ea6e59dbcbe9859a-applied.json`.

- canonical 값 SHA256: `f11824e89db983e7a75bf5e1beb421dc10db6985bb6b4581a0ee0140524a79f2`
- binary 청크 목록 SHA256: `59f29d52a2ecf30a6dd7c0d3e75a1e349b67d399ba72f748ccf82551ce25d264`
- 승인 역할: `MEASUREMENT_AND_CONTROL_NOT_ALPHA_APPROVAL`

검증은 서로 다른 세 단계다.

1. 전체 2,119,881개 값을 별도 SQLite 공식으로 재계산해 Python과 대조.
2. 성과를 보지 않고 고정한 10개 asset의 전 기간 7,072행을 PostgreSQL 공식으로 대조.
3. 적재된 모든 행·모든 필드의 binary chunk SHA256을 Python과 대조한 뒤 commit.

3번은 표본 검사가 아니다. 문자열 길이/UTF-8, asset ID, 날짜, 마이크로초 시각,
float64 비트까지 포함한다. `readback_sha256`은 binary 청크 목록 해시이고
`values_sha256`은 canonical JSON 값 해시이므로 서로 다른 값이다.
소규모 실제 PostgreSQL probe와 별도 psycopg binary encoder 대조도 통과했다.

첫 원문 전체 다운로드 방식은 SSM 전송에서 지연돼 해당 발행 트랜잭션을 rollback했다.
완료되지 않은 적재를 성공으로 처리하지 않았고, 위 전수 binary 방식으로 다시 발행해 확인했다.
조회 API도 명시적 parquet snapshot을 전송 캐시로 사용할 수 있지만, DB metadata와 전 행
binary 대사를 매번 실행한다. 로컬 파일만 믿는 offline fallback은 없다.

commit 이후 새 연결에서 `load_active_references()`를 실제 실행해 활성 program→catalog→DB→
전 행 대사까지 다시 통과했다. 반환은 7종·2,119,881행·역사적 종목 3,160개였다.
규모/모멘텀 두 측정치의 소비자용 결합도 320,056행으로 확인했다. 모멘텀 준비기간 등의
결측 37,185건을 그대로 남겼으며 0으로 채우거나 투자 유니버스라고 간주하지 않았다.
DB의 9개 불변성/생성 트랜잭션 guard trigger도 활성 상태임을 확인했다.

기존 Gold metadata는 발행 전후 동일성만 비교하며 이전 팩터 성과를 연구 입력으로 읽지 않는다.
새 데이터는 `gold.reference_*`에만 저장하며, 기존 `gold.factor*`는 수정하지 않는다.

## 실제 실행한 소프트웨어 검증

- 합성 전체 실행: **30개 검사 통과, 의도한 잘못된 요청 8개 거부**.
  원본 캡처→입력 연결→경쟁 가설→두 검사→독립 fixture 검토→직접 전략/릿지 전략→
  네 변형 실행→권한 철회/원천 무효화→후속 실행 차단까지 연결했다.
- 최종 데모: `output/phenomenon-software-demo-20261002-final/manifest.json`.
  미래 2030 연구 시각은 합성 시점 검사 장치이며 시장 자료의 실제 가용일이 아니다.
  마지막 `DEPENDENCY_BLOCKED` 상태는 의도적 원천 무효화 검사가 성공한 결과다.
- 신규 경로 최종 회귀검사: **387개 통과**. 선택적 캐시 조회의 변조·스키마·잘못된 dataset·
  DB 불일치 차단까지 포함한다.
- 통합 작업 중 수행한 전체 저장소 검사: **2,937개 통과, 기존 레거시 검사 1개 실패**.
  이후 신규 코드의 최종 변경은 위 신규 경로 회귀검사로 다시 확인했다.

  에서 변경된 revenue 원장을 거부하지 않는 기존 경로 문제다. 신규 가격 라이브러리에는
  해당 overlay를 사용하지 않았으며 이를 “전체 테스트 통과”라고 보고하지 않는다.
- 두 저장소 `git diff --check` 통과.
- 신규 모듈/CLI `compileall` 및 저장소 연구 스킬 validator 통과.

## 아직 주장하지 않는 것

- 호스트 에이전트가 질문·검색·검사 방향·검토를 판단한다. CLI 자체에 독립 LLM이나 상시 스케줄러는 없다.
- 현재 실행 연산은 coverage, 평균 차이, 상관의 서술통계다. 블록 부트스트랩·패널 회귀·
  인과 추론·반복 검정 보장은 추가 계약/테스트가 필요한 확장이다.
- 해시와 DQ 인증은 최초 발표 vintage의 독립 확인이 아니다. 가격 feature의 기존 수용 계약과
  관측일 종료 시각 가정을 남겼으며, `PIT_ASSUMED`를 `PIT_VERIFIED`라고 바꾸지 않았다.
- 실제 새 시장 가설 연구·실증 교훈·새 OOS 확인·수익성 승인·자동 주문은 수행하지 않았다.
- 레퍼런스 조회가 투자 유니버스·TR label·시가 체결·시장 벤치마크를 자동으로 만들어주지 않는다.
  개별 전략에서 별도 원천 계약을 고정해야 한다.
- 이번에는 Git 커밋/메인 병합/웹사이트 배포를 하지 않았다.
