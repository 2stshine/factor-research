# 연구 v2 실행과 기억 사용

이 문서는 최초 여섯 정의 파일럿의 동결 범위를 설명한다. 이후 신규 캠페인 기본 연결은
[일반 연구 운영 안내](research-v2-production.md), 검토된 범위 전이는
[기억 전이 계약](research-v2-memory-transfer.md)을 따른다. 최초 비교 결과는 소급 변경하지 않는다.

이 경로는 동결된 개발 자료에서 설명 절차를 비교하는 별도 실행기다.
팩터 승인 campaign, 일회성 OOS, SQL parity, Gold 게시를 대체하지 않는다.
실험자가 직접 정답 파일이나 원시 패널을 여는 권한을 기술적으로 모두 차단한 시스템은
아니며 호스트의 접근 통제가 필요한 논리적 격리다.

## 역할과 입력

1. 준비자는 입력 identity·총수익 계보를 읽기 전용으로 확인한다. 공개 가능한 정의 색인과
   연구 질문으로 후보를 먼저 정하고 자료·기간·수식·코드·예산을 동결한다.
2. 실제 진단 에이전트는 `PilotBroker.packet`과 `act`만 사용한다. 각 팩터와 비교 방식은
   다른 문맥에서 실행한다. 필수 증거를 생략할 수 없고 임의 코드나 자료 구매는 요청으로만 남긴다.
3. 종료 결과 해석자는 `prepare-review`가 내보낸 동결 근거만 읽는다. 사실, 해석,
   대안 설명, 미확인 자료, 미실행 후속 검사를 정성 초안에 분리한다.
4. 별도 문맥의 비평자가 실제 원문과 인용을 대조한다. 실제 ACCEPT가 현재 초안 해시에
   결합되어야 활성 기억에 들어간다. 형식 검사는 경제적 진실 판정이 아니다.
5. 다음 연구자는 검색된 정성 기억과 그 범위·한계를 읽고 사용/배제 이유를 기록한다.
   본 비교는 같은 과거 자료의 재분석이지 새로운 독립 표본이 아니다.

## 기억 경계

- v2에서는 기존 `KNOWLEDGE.md`의 데이터 계약과 정의/시도 색인을 계속 참고한다.
  그 파일의 과거 경험 교훈은 보관 기록이며 새 v2 활성 기억에 자동 수입하지 않는다.
- 기존 운영 campaign의 지침과 기억 경로는 소급 변경하지 않는다. v2 연구자가 두 기억
  경로를 무심코 같이 주입하면 안 된다. 이전 결과를 이미 본 호스트의 노출 이력도 사라지지 않는다.
- `research/v2/active-memory.json`은 실제 활성화된 저장소와 검토본을 가리킨다.
  원본 결과를 찾는 우회 경로가 아니며 공개 해석자용 통계 번들은 후보 생성자에게 주지 않는다.
- 현재 CLI는 **정확히 일치하는 원래 사례 범위**에 한해 검색한다. 다른 시장·정의·기간으로
  자동 일반화하지 않는다. 새 범위로 이전할 교훈은 별도 제안과 비평이 필요하다.
- 검색 시점은 연구자가 교훈을 알게 된 시점이다. 이를 과거 시장에서 알고 있던 정보로
  소급하지 않는다. `research_as_of`와 시장 신호일을 구분한다.
- 효용 가중치는 영이고 그래프 검색은 사용하지 않는다. 조회/사용 횟수를 인과적 효용으로 보지 않는다.

## 완료 실행 재사용

기존 실행을 다시 평가하지 않고 읽는 예시:

```bash
.venv/bin/python -m scripts.research_v2 --help
.venv/bin/python -m scripts.research_v2_memory retrieve \
  --release-root output/research_v2_pilot/release-20261002-v1 \
  --database output/research_v2_pilot/release-20261002-v1/active-memory.sqlite \
  --task-id new-review-task --key new-review-retrieval \
  --case net_roa --query '수익성 통제 실적 비용'
```

실제 반환된 revision과 receipt를 읽은 뒤 `usage`에 사용/배제 이유를 제공한다.
같은 idempotency key로 다른 작업을 쓰지 않는다. 자료가 없거나 범위가 다르면 검색 영 건이
정상이며 비슷해 보이는 과거 성과를 임의로 가져오지 않는다.

## 도입 결정

실제 파일럿에서 선택형의 일반적 우월성을 확인하지 못했다. 따라서 근거별 필수 검사와
독립 비평을 기본 안전장치로 유지하고, 에이전트의 검사 순서·후속 질문 선택은 제한적
보조 기능으로 운영한다. 승인 수나 알파를 보상으로 삼는 자동 탐색은 도입하지 않는다.
새 연구를 반복 실행하는 자동화나 전 연구의 운영 전환이 이 문서만으로 생기지는 않는다.
