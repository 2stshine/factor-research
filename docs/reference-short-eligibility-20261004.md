## 월말 계산과 결측

`공매도 비중 = 허용·가용 거래일의 공매도 체결수량 합 / 같은 거래일의 수정 전 KRX 전체 거래량 합`

분자와 분모에 반드시 같은 날을 사용한다. KIS `venue=J`, payload의 KRX 시장 범위와
수정 전 거래량을 확인하며 NXT/통합 거래량을 섞지 않는다.
최소 **15개 허용·가용 거래일**, 해당 일수 전부의 원천 관측, 수량·시각·식별 정합성을 요구한다.
실제로 관측된 공매도 0은 유지한다. 결측과 금지를 0으로 바꾸지 않는다.
변화는 바로 전 달의 유효 비중과 비교하며, 공백을 건너 비교하지 않는다.

가용시각은 기존 정책인 **다음 달력일 08:30 KST**를 유지했다.
다음 달 1일 00:00 KST 전에 가용하지 않은 거래일은 월말 계산에 들어가지 않는다.
따라서 2020-03·2025-03의 일부 허용일, 2023-11의 처음 3거래일만으로 월별 지표를 만들지 않는다.

부분 재개 구간에서 개별 제한 **1,102종목-일**을 제외했다. 허용일 중 원천이 없는
**1,059종목-일**은 결측으로 남겼다. 이를 허위 0으로 채워 커버리지를 늘리지 않았다.
기존 비중 54개·변화 97개의 제외는 모두 개별 제한일 적용 후 최소 15일을 충족하지 못한
현재 월 또는 직전 월로 설명된다. 기존과 겹치는 비중 3,029개·변화 5,416개의 값도
제한일 제외에 따라 달라졌으며, 구버전 값은 보존했다.

## 검증과 실제 저장

1. 단위·회귀 및 기존 발행/소비 경로 테스트 **143개 통과**.
2. 부분 재개 구간 전체 일별 원본을 별도 Python 경로로 재집계했다.
   2021-05~2023-10 **72,164종목-월**의 일수·분자·분모·가용시각이 DB SQL 집계와 일치했다.
   2023-11의 2,521종목-월 및 금지 후에만 관측된 17종목도 구분하여 확인했다.
3. 고정 규칙으로 선택한 20개 asset_id의 전체 기간 원본 **38,623행·1,959종목-월**을 추가 대조했다.
4. 제한일 처리에 영향받지 않는 179,009종목-월의 원천 합계가 이전 원천 집계와 일치했다.
5. 최종 두 측정치 각각의 전체 SQLite 계산과 고정 종목 PostgreSQL 계산을 대조했다.
6. 나머지 106개와의 겹치는 관측에서 동일/아핀 동등 측정치 중복을 검사했다.
   두 v1은 명시적 대체 대상으로만 취급했다. 이것이 독립 경제적 알파를 입증하는 것은 아니다.
7. Gold 원자적 커밋 후 **344,144행 전체**의 바이너리 청크 해시를 대조했다.
   구버전 두 데이터셋도 전체 재조회했다. 나머지 106개의 정의·데이터셋 연결·기존 검증 캐시 해시·실제 행 수는 유지했다.
8. 활성 연구의 `load_active_references → reference_fields` 경로로 새 두 지표의 **344,144개 값 전부**를 다시 읽어 대조했다.
