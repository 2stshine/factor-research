## 주석과 계산, 점수 공간을 섞지 않기

현재 `labels.jsonl`은 230행이다. `cat_data` 미기록 177행, `jkp_theme` 미기록 182행,
`variant_of` 미기록 217행이다. 분류가 비어 있음을 해당 경제 영역을 탐색하지 않았다는 뜻으로
해석하지 않는다. 과거 `Factor.exploration_domain`을 채우면 정의 hash가 달라질 수 있어 수정하지 않았다.

팩터 공간은 이미 인증된 공개 시행의 frozen source와 params를 사용한다. 현재 코드와 과거 시행의
이름이 같다는 이유로 identity binding을 보충하지 않는다. 별도 주석은 record ID·definition hash·
packet hash에 결합해야 한다. 분류에 성과·현재 승인 여부를 사용하지 않는다.

경제적 메커니즘의 가설 문장, 코드가 같은 계산 변형, 실제 공통표본에서 중복되는 점수는
서로 다른 축이다. 코드 묶음 개수를 독립 효과 수로 제시하지 않는다. 공통 종목-월 점수 행렬이
없으므로 유효차원은 NOT_COMPUTED다. 쌍별 상관 중앙값 표는 PSD 보장이 없어 고유값 분석의
대체 입력으로 쓰지 않는다. 묶더라도 실제 시행/다중검정 수는 그대로다.

## 정성 교훈의 다음 사용

`research/INSTRUCTIONS.md`는 종료·공개된 정성 교훈과 pass/fail 활용을 의도적으로 허용한다.
이 흐름을 제거하지 않았다. 상세 OOS 숫자·성과 순위·최적 파라미터를 새 후보 입력으로 추가하지 않는다.

선택 도구 `engine/knowledge_lineage.py`와 신규 `engine/knowledge_registration.py`는 지식
스냅샷과 명시적 참조의 review/packet 버전을 신규 epoch 등록에 결합한다. 캡처 명령과
`epoch-start --knowledge-capture`를 선택한 새 후보만 적용한다. 필드가 없는 기존 연구는
NOT_RECORDED다. 후보 loader의 실제 출처·파일 hash·선언·캡처 당시 공개 검토본·등록 시각을
대조하며, 과거 기록을 소급 변경하거나 독립 OOS·실제 인과 영향·follow-up 실행을 만들지 않는다.
전체 메모리 내용 심사/자동 후보 feed가 아니며 실제 새 등록·실험은 실행하지 않았다.
[상세 계약과 한계](knowledge-lineage.md)를 참조한다.

  원래 보호 파일 718개 중 선택적 신규 등록 연결을 추가한 `engine/epochs.py` 외 717개 hash 유지.
- 벤치마크·기존 월초 비교·배당 준비 회귀: 228개 테스트 통과. 동결 실행 파일·계획·catalog 보존.
- 새 성과, 독립 재현, 실제 체결 또는 데이터 접근 권한을 테스트 숫자에서 추론하지 않는다.

## 제한된 frozen source 진단과 신규 등록 연결 완료

공개 팩터 공간 `#coverage?section=inputs`에서 코드가 참조하는 필드·연산·기간을 별도로 탐색한다.
분모는 같은 공개 177건이며 규칙 내 추출 165건, 부분 11건, 미해석 1건이다.
