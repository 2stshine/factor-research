# KOSPI 월말 레짐 — PIT_ASSUMED

사용자의 명시적 가정 기반 진단 사용 정책으로 연결한 파생 입력이다. 역사적 PIT 검증 완료나 최초 발표본 인증이 아니다.

- 원시 마지막 거래일: 2026-07-16. 최신 원시월 2026-07은 보수적으로 제외.
- 사용 입력: 2015-01~2026-06, 138개월. 룰 monthly-trend-vol-v2 그대로.
- 네 축 최초 READY: 2018-01; 전체 READY 102개월. 초기 warm-up은 UNKNOWN/PARTIAL이며 기준을 완화하지 않았다.
- known_at 월말23:59:59는 KST 의사결정용 가정 bound이며 실제 수신·발표 시각이 아니다. 원시 거래일은 별도 보존한다.
- 지수별 원시일이 로컬 KRX 달력 합집합과 일치하는지 확인한다. 모든 로컬 소스에서 함께 사라진 거래일은 확인할 수 없어 달력 완전성 가정을 명시했다.
- provenance.json에 원시 파일 SHA·거래일·원문 행, 정책 및 승인 바인딩은 approval.json/context.json에 보존.
- timeline.json은 시장 상태만 분류한다. 팩터 성과, OOS, DB, 기존 캠페인, Gold는 읽거나 변경하지 않았다.
