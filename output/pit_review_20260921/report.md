### 확인된 사실과 아직 입증하지 않은 사실

- **DART:** 기아·디와이에이·디아이의 2015 사업보고서 로컬 자료는 각각 2021년·2021년·2023년
  정정본만 있다. 공식 최초본은 모두 2016-03-30 제출이다. 현재 변환은 정정 접수일 다음날부터
  사용하므로, 이 발견은 최초본 누락/과거 자료 부족의 증거다. **금액 차이나 live RDS 미래누출을
  확정한 것은 아니다.** 선택한 3건으로 전체 오류율을 추정하지 않았다.
- **KRX:** 2,894행은 로컬 명칭 분류규칙의 실제 차이다. RDS의 식별자·인증·상장기간 필터를
  적용한 최종 연구 유니버스 영향 수가 아니다. 우선주 정규식은 `신우`·`동우` 같은 일반 명칭에도
  반응하므로 과거 이름으로 단순 교체하는 것만으로 해결되지 않는다.
- **수정주가:** 미래 기업행사로 과거 가격 수준이 재조정될 수 있다. 동일 배율이 상쇄되는
  수익률까지 전부 오염이라고 판단하지 않았다. 원가격 정정, 반올림, 절대수준 결합은 별도 검사가 필요하다.
- **FMP CPI:** 2024-04 전월비 FMP 0.0%는 [당시 공식 브리핑의 현재 보존본](https://www.korea.kr/news/policyNewsView.do?newsId=156628649)과 일치한다.
  최신 자료의 0.1%와 다르다는 이유만으로 FMP 오류나 미래누출을 단정하지 않는다.
  이 한 건의 일치도 전체 빈티지 인증은 아니다.
- **수익률 label:** `total_return_close`는 사후 실현 성과를 측정하는 label 전용이며 predictor로
  차단돼 있다. 사후 결과값과 당시 판단 입력은 다른 계약이다. 이를 전체 입력 PIT 승인의 근거로 쓰지 않았다.

## 전체 레짐 완성 전 사전검사

`review_scope.json`은 신규 FMP 37개, 기존 FMP 9개, KRX 지수 4개, 현재 연구 입력 2그룹,
KIS 2그룹, 별도 승인 정책금리 파생 축 1개를 **55개 검토 단위**로 고정한다.
서로 다른 계열 수나 사용 가능한 feature 수가 아니다. 특히 원시 정책금리와 승인 파생 축을 중복으로
합쳐 전체 원시 자료가 승인됐다고 계산하지 않는다. 요구 기간은 2015-01~2026-08이다.

신규 `scripts.regime_readiness`는 검토 근거 해시, 별도 승인 context, 승인 범위, 필요한 월의
가용시각·UNKNOWN·워밍업을 확인한다. 하나라도 준비되지 않으면 `--require-complete`가 exit 2로
종료한다. 이것은 **요청된 전체 완성의 사전검사**이며 원문 진실을 자동 인증하는 도구가 아니다.
기존 캠페인 실행 정책을 변경하거나 자동으로 전체 연구를 중단시키는 생산 환경 배포는 하지 않았다.

[실제 실행 결과](readiness.json): **PARTIAL**, `READY` 1개(정책금리 140개월),
`EVIDENCE_INCOMPLETE` 54개, registry 해시 확인 성공, `--require-complete` **exit 2**.
이는 감사 단위의 준비 상태다. **1/55를 데이터 PIT 커버리지로 해석하거나 54개를 오염 건수로 세면 안 된다.**
현재 연구 입력 DART/KRX는 정책금리 진단 context로 대신 인증할 수 없도록 별도 차단한다.

```sh
.venv/bin/python -m scripts.regime_readiness \
  --manifest output/pit_review_20260921/review_scope.json \
  --registry research/regime_sources.json \
  --output output/pit_review_20260921/readiness-next.json \
  --require-complete
```

출력은 새 파일만 허용한다. 미확인 소스를 목록에서 자동 삭제하지 않고, 자료 없는 월도 채우지 않는다.
기존 campaign·승인 registry·Bronze·Silver·Gold는 수정하지 않았고, 새 레짐 분석·팩터 평가·OOS 열람을 하지 않았다.

## 다음에 해소할 순서

1. **RDS 터널 복구:** 실제 연구 cohort의 접수번호·분류·가용시각과 FMP/KIS 수신시각 집계를 확인한다.
   로컬 통계를 live 인증 행 수로 간주하지 않는다.
2. **DART 공시 버전 복원:** 공식 [전체 제출 목록](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019001)의 `last_reprt_at=N`으로 최초·정정 목록을 확보하고,
   [접수번호별 XBRL](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019019) 금액·공개일·해시를 결합한다.
   2015년부터 전수 복원은 이번의 제한된 문서 검색보다 큰 수집 작업이다.
3. **KRX 신원·시장 축:** 법적 종류주/합병·SPAC 전환 효력일 이력과 실제 결정 cutoff를 연결한다.
   지수 출시 전 자료는 따로 분리하고 필요한 공식 공표/정정 원본을 확보한다.
4. **FMP/KIS 빈티지:** 현재값 대조로 대체하지 않는다. 원 발표·후속 수정 버전이 없는 부분은
   공급자 이력 또는 공식 발표 아카이브가 필요하다. 없는 과거 수신시각을 생성하지 않는다.
5. **완료 사전검사 통과 후:** 새 캠페인에만 동결 입력을 연결하고 기존 고정 레짐 규칙으로 진단한다.
   전체 원본 확보가 불가능한 소스는 제외 범위를 사용자가 결정해야 하며 자동으로 승인하지 않는다.
