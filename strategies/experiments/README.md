# experiments

전략 레이어의 **실험 기록과 산출물** 보관소. 설계 문서(`../README.md`)에는 결과를 두지 않고
여기에만 남긴다.

## 규약

- 실험 하나 = 파일 하나. 이름은 `YYYY-MM-DD-주제.md`.
- 각 문서에 **무엇을·왜·어떤 구간에서** 측정했는지와 **한계**를 함께 적는다.
- 백테스트 산출 CSV 등 실행 결과물도 이 폴더에 저장한다.
- 실험용 코드는 본 파이프라인에 섞지 않는다. 필요하면 일회성 스크립트로 작성하고,
  결론만 문서로 남긴 뒤 코드는 지운다.
